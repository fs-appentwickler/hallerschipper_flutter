# Hallerschipper

Native Flutter-App für Android, iPad/iPhone und macOS.

## Funktionen

- 128 vollständig offline verfügbare Liedtexte
- Suche nach Liednummer, Titel und Text
- Filter nach Kategorie
- Übersichtliche Liedansicht für Tablet und Desktop
- Originales Hallerschipper-Logo und Farbschema

## Start

```bash
flutter pub get
flutter run
```

Für die Installation auf einem iPad muss in Xcode unter
`Runner > Signing & Capabilities` ein persönliches Team ausgewählt sein.
